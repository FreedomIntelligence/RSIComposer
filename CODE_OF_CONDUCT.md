# Community expectations

Keep discussions respectful and focused on the work. Welcome questions and
different levels of experience. Critique behavior, evidence and implementation
choices without attacking people.

Harassment, discriminatory remarks, threats, deliberate disruption and sharing
another person's private information are not acceptable. Do not post private
run data, credentials or personal information in reports.

Maintainers may remove inappropriate content, limit participation or close
discussions to protect the community. Report conduct concerns to the repository
owner through an available private GitHub channel; if none is available, request
a private contact without publishing the details. Maintainers should handle
reports discreetly and apply these expectations consistently.

These expectations apply to project issues, pull requests and other official
project spaces, including maintainers' participation.
