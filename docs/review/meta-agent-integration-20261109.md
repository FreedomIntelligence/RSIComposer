# 2026-11-09：FT-Agent / AIDE 注册接入验收

两个方法均已通过现有注册边界执行真实模型闭环。框架仍只有决策器与 Lab 两类顶层对象，
没有新增一套研究运行器，也没有由维护者选择 candidate 或替代算法决策。
这次验收证明注册架构能承载研究型 meta-agent，不等于完整复现原论文收益。

| 注册决策器 | 注册 Lab | 保留的原生逻辑 | 执行适配 |
| --- | --- | --- | --- |
| `ft_agent` | `llm_finetune` | 固定 RD-Agent 版本的假设生成、数据/配置生成、反馈接受和 FTTrace 选择 | 冻结 GSM8K、小预算 LoRA、原生 LLaMA-Factory、独立数学评分 |
| `aide` | `aide_program` | 固定 AIDE 版本的 Agent、搜索树、审查、Journal 与最终选优 | GSM8K 推理程序任务、隔离 Python、固定模型推理代理、宿主评分 |

FT-Agent 是明确的本地参考适配：按名称加载固定版本的原生定义及提示，避免场景导入时
自动下载全部 FT-Dojo 数据和部署环境；没有包含完整 CoSTEER 知识/调试流程与 OpenCompass。
AIDE 使用原生 Agent 的执行 callback，在每个候选处停下来调用已注册 Lab，
而非把整个外部研究 CLI 包成一次黑盒操作。研究运行时的独立解释器由通用消息桥接管理。

## 实验结果

- FT-Agent：64 题训练、32 题开发、64 题独立测试，三次原生三卡 SFT 各 32 步，
  数值合并与重载评测成功；8 条真实回执全部完成。开发成绩为 24→27→29→22 / 32，
  原生逻辑选择第二轮；独立测试为 48→45 / 64，下降 4.6875 个百分点。
- AIDE：8 个公开示例、32 题开发、64 题独立测试，原生搜索 draft→improve→improve，
  5 条真实回执全部完成；独立测试为 28→34 / 64。同时调用数从 29 增到 67、
  token 从 19,552 增到 48,762，不能当作等计算预算收益。

两项都是单种子、小规模、改编任务；FT-Agent 的目标模型为 Qwen2.5-7B Base，
AIDE 的固定推理模型与两者的研究模型使用同一个本地 Qwen3.5 架构 checkpoint。
这不是两种算法的受控横向比较。现有结果不足以把与论文的差距归因到论文。
详见 [FT-Agent 结果](../../experiments/ft_agent/RESULTS.md) 与
[AIDE 结果](../../experiments/aide/RESULTS.md)，其中列出所有初期失败和本地适配修复。

## 本轮发现并处理的问题

1. FT 数据描述与错误日志交付不完整、AST 加载遗漏 `yaml`、YAML 科学计数法字符串
   被误拒绝，均为本地适配问题；已修复并保留失败证据。
2. FT 的 GSM8K 金标与 boxed-only Math-Verify 格式不匹配，曾把正确回答全部判错。
   无效运行已停止，修正后的完整运行单独保存；新增真实评分器正反例，训练金标不改写。
3. Qwen 的 system-only / forced-tool 服务兼容要求已显式适配；不宣称与论文模型 API 相同。
4. 原生进程桥与隔离执行清理不能只检查父进程退出；现在对拥有的进程组继续清理，
   覆盖父退出、后代拒绝 TERM、重复关闭等真实进程回归。
5. 终局执行失败不能报告 completed，模拟回执不能当作真实执行，自修改 candidate
   不能保留有效质量指标；AIDE 增加拒绝路径与回归。

## 架构结论与范围

新增方法没有要求修改循环调度器或增加核心对象，符合两类注册接口的定位。
固定版本的原生研究逻辑拥有策略决策；框架负责请求/回执配对、执行、隔离、产物身份
与生命周期。生成程序不能读取私有金标、访问宿主 TCP、直接占用 GPU 或修改宿主训练配置。
独立留出分数在原生最终选优之后产生，不反馈给搜索。

当前仍有明确的底层缺口：同步长调用没有持久化恢复或外部作业 reconciliation；
注册不提供全局 GPU lease；模型调用与训练成本没有完全归入统一账本。
搜索状态保留在原生 worker 内，不能只恢复宿主 JSON 后假设原生进程继续运行。
这些是后续核心能力，不能用注册外壳冒充已经实现。

本轮按 GPU 0–3 / 4–7 分配任务。AIDE 记录到各卡峰值 100%，平均利用率未满；
FT 最终运行的监控脚本失败，只有原生多卡参与证据，不能声称全程满载。
收尾时所有自有服务已释放，8 张卡均为 0 MiB。原远端脏工作树和用户已有历史文档未修改。
