## 判断与架构边界

可以先作为 **0.1 研究框架** 发布。主要扩展对象继续是 RSI 决策器与 Lab；
meta-agent、SFT、RL 和纯 harness 方法使用同一公共循环。
方法注册不需要再建立平行运行器，harness、memory、scorer 和引擎可在两个模块内部替换。

即使用户完全自定义两个模块，公共运行时仍承担注册身份、授权、操作路由、反馈交付、
执行账本与所有权清理。需要新的交付、恢复、调度或预算语义时，应扩展核心并补回归。
插件内部任意调用不因注册而自动被计费、隔离或恢复。

本轮没有证据支持大范围重写内部 harness 或兼容端点。先保持现有行为与接口，
把公共契约、默认实现与当前限制分清，比仅为文件大小拆分核心更适合首版范围。

## 后续核心工作

1. 为 FT-Agent/AIDE 原生搜索、RRSI 和同步 GPU 方法接入明确状态与外部作业核对，验证不会重复训练或搜索副作用。
2. 同步训练 Lab 复用 submit/poll/cancel 与心跳能力，接入可执行的长作业预算中断和统一成本记录。
3. 跨 Lab/run 的 GPU lease；目前只有显式设备配置和 mask 检查，资源划分由操作者负责。
4. 在 TTRL 专用桥接之外形成可复用的 verl/FSDP engine，按算法、执行和恢复分别验收。

这些是后续核心里程碑，不是算法注册层的配置工作，也不阻塞定位清楚的研究版。
论文全规模收益、meta-agent 自身权重训练、任意插件自动恢复与多租户运行不在首版承诺中。
