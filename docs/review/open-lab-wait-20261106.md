## 执行能力

`lab_poll(job_id)` 和 `lab_poll(job_id, wait_seconds=0)` 仍立即返回原生状态。
模型可自行选择正数 `wait_seconds`，最多等待 host 声明的上限，默认 30 秒。
进程结束、等待时间用尽或 host 中断时返回当前状态。等待本身不启动、取消程序，
也不自动收集结果。读取状态、日志、文件和结果不受此参数限制。

医疗入口通过执行器回调响应原绝对截止、停止和暂停；等待上限不延长任何研究预算。
等待耗时和结束原因仅属于本次查询，不写进缓存的终态回执；同一 producer event 的
`lab_result`、归档与恢复保持一致。无效等待参数返回可恢复的工具错误。

同一个 meta-agent 继续选择算法、编写训练/加载/推理代码并管理 task/memory。
本修改不引入固定训练流程或独立整理模型。固定正式评测保持原协议。

## 验证

回归覆盖真实 CPU 子进程的即时查询、有限等待、原生失败、取消、host 中断、
恢复后查询，以及一次等待只消耗一次决策并把原始失败交付下一次决策。
医疗装配验证暂停、停止、绝对截止均接入等待中断。
测试结果和只读审计来源记录在同目录 repros 的验证文件中。

本次验证属于执行与反馈集成，不构成模型自主训练或医学提升的实测。
