# 研究闭环修订：行为反思、任务验收和运行检查

2026-11-08。基于九小时医疗实验的终态证据：新两轮 LoRA 的 optimizer 已到
128 步、checkpoint 权重发生变化，但新候选正式评测因缺少 `candidate_adapter`
失败；三次完成反思均为 `no_change`，后续反思重复读取首页；最后 attempt
继承两条 Memory，读取三次，没有新增。训练成功不等于能力提升。

## 改动与边界

保留单一 meta-agent、现有 Lab 执行与版本激活接口。没有增加整理模型或并发写状态者。

### 反思面向行为改进

反思指令明确将路径猜测、分页重启、忽略记忆、提前关闭任务列为可改进目标。
工具运行正确不能单独构成 `no_change` 的理由。报告增加 `behavioral_review`：
`failure_pattern`、`proposed_change`、`validation_plan`、`no_change_reason`。
前三项要求非空，`no_change` 还需填写不改或暂缓的理由；报告不证明这些判断正确。
既有实际组件绑定校验继续区分 changed 与 no_change，改善仍需独立测量。

新增只读 `reflect_read(window_id)`，从已经返回并进入真实历史的完整原文页面计算
下一缺失页。它复用授权 archive 和原始 hash 校验，返回原文及 `archive_request`，
不总结、不自动跳过证据，也不替 agent 发起修改。重复调用会在历史记录提交后向前推进。
没有新增反思操作次数上限，原最长一小时和宿主绝对截止继续生效。

### 任务关闭有明确结果和回执

关闭必须给出 outcome 与 resolution：resolved、abandoned、inconclusive、interrupted。
resolved 还要求 task 上的 `acceptance_checks` 全部匹配。每项包含 id、operation、
result_path（回执 result 内 JSON Pointer）和 expected 标量，关闭参数
`acceptance_evidence` 将 check id 绑定原生历史 record_id。

宿主校验操作名称、原生非模拟成功、终态作业、字段值和源记录 SHA。提交确认、失败作业、
训练成功但没有评测字段、样本不足的回执都不能满足完整评测条件。绑定与恢复时重验来源。
这些是通用回执谓词，核心 Memory 不认识医学指标。医学任务可声明固定评测 verified
和 n=500；训练、加载、完整评测也可拆成不同任务。

验收条件仍由 agent 选择，宿主不能证明它们完整表达了自由文字目标；把条件写得过弱仍然
可能漏检。旧任务保留历史含义，不自动升级成 verified。continuation 需要显式清理放行
所有验收来源，并在新历史前缀下重算来源 SHA。旧无分类关闭导入后记作 inconclusive。

### Memory 关注后续行动价值

提示明确将确认过的产物路径、打包依赖、操作顺序和防止错误重犯的程序作为知识。
producer inbox 提供按 operation/error/summary 字段匹配的重复失败导航，含精确来源引用。
同一作业的重复终态轮询只算一次，无作业 ID 的独立失败调用分别计数；相同回执的
Memory 审阅义务仍去重。
这不判断共同病因，也不生成笔记。not_useful 的判断需考虑操作复用价值，仍允许有理由的
处置。没有笔记数量配额；写入、检索和后续行为改善分别报告。这里未加入自动语义判断，
也未声称提示修订足以让当前模型一定写出正确记忆。

### 正式评测前执行相同 bundle

新增异步 `medical_smoke_test(key, submission_path)`，在既有 Lab 生命周期、隔离策略和
安装运行环境下，对冻结 bundle 执行最多两个公开输入。使用同一正式候选入口与原公开
输入提示，校验返回输入 ID 和非空预测；不计算准确率、不访问封闭数据、不占封闭 slot。
它确实运行候选代码，消耗 Lab 时间与资源，最长取 300 秒和宿主 job timeout 较小者。
宿主全局 admission/cutoff 和 supervisor 仍负责绝对截止。

默认正式评测要求该 bundle 内容与运行环境下存在通过的运行回执；改动任意候选文件、
注册基模身份或运行环境后旧回执不再满足准入。运行检查和正式评测共用现有作业恢复状态，
已提交同 key 不自动执行第二次。宿主兼容装配可显式设置 `require_smoke_test=False`，
配置进入恢复身份，agent 无此开关；既有评分/隐私测试用它单独检验评分逻辑。

`medical_preflight` 继续准确表示结构检查。运行检查通过表示候选入口能对少量输入运行，
不能独立证明代码真正加载了所声明权重，也不能排除其对全量数据的分支错误。
回执明确 `model_load_verified=false`、`scored=false`。完整固定评测和实际权重加载证据
仍是训练收益的必要证据。漏带模块会在这一步成为普通失败；宿主不会偷偷修候选代码。

## 验证

新增回归覆盖：训练/提交/部分评测不能关闭完整评测任务、来源篡改拒绝、验收来源跨
attempt 重绑定、只读分页连续推进与恢复、反思结构化计划、重复失败导航，以及真实
隔离子进程中的缺依赖失败、补齐依赖成功、bundle 改动失效、无效预测拒绝、幂等恢复、
截止发生于 freeze 后不启动进程。全部是协议或符号输入验证，不是医学能力测量。

最终本地 Python 3.12 完整回归：1950 项，1905 通过、45 跳过，耗时 126.776 秒。
Linux 独立回归目录中运行 Memory、反思、continuation、医疗协议与装配、宿主执行边界、
恢复和上下文预算相关测试：128 项全部通过，耗时 124.746 秒；14 个修改的代码/测试
文件与本地逐 SHA-256 一致。未启动模型推理或训练，没有修改旧实验冻结源。
完整回归中曾遇到旧 Qwen toy 的 150 毫秒截止测试偶发失败；该项单独复跑通过，
随后完整回归通过。未修改这项旧测试或放宽其断言。

真实 agent 的验收应比较同一冻结任务上的完成率、重复失败次数、Memory 原文引用后的
行动、实际激活版本、调用与时间成本；不能将新字段填齐或测试通过等同于研究能力提升。
