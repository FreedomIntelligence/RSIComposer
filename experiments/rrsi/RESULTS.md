# 2026-11-08：固定模型 MATH pilot

这是 RRSI 在 MATH 上的小规模算法移植实验，不是原论文指标复现。
分析、提案、critic 和解题都使用同一份 Qwen3.5-9B checkpoint，关闭 thinking。
模型四个权重分片的运行前后 SHA-256 一致；没有 RL 或权重训练。

搜索使用 64 道 MATH train 题，独立留出使用 seed=7308 打乱 MATH-500 后的 128 题，
每题两次采样；三个搜索轮次，每轮两个提案槽，每槽最多三次尝试。
数据版本、文件哈希、逐次测量和采纳记录见 [机器可读结果](results-20261108.json)。
数据源固定为 `EleutherAI/hendrycks_math@21a5633873b6a120296cce3e2df9d5550074f4a3`
与 `HuggingFaceH4/MATH-500@6e4ed1a2a79af7d8630a6b768ec859cb5af4d3be`。

| 运行协议 | 实际评测候选 / 采纳次数 | 初始留出准确率 | 最终留出准确率 | 初始 / 最终平均 policy token |
| --- | --- | --- | --- | --- |
| 普通 JSON | 3 / 0 | 205/256（80.08%） | 202/256（78.91%） | 1176.17 / 1174.08 |
| JSON Schema | 4 / 3 | 204/256（79.69%） | 214/256（83.59%） | 1165.34 / 920.48 |

普通 JSON 运行出现 15 次 JSON 解析拒绝；三个被评测候选都破坏了答案输出，得分为零，
决策器自动保留初始 harness。初始和最终源码相同，因此两次留出分数的变化只是采样波动。

第二次运行启用了 JSON Schema，并将 analyst / critic 输出上限调整为 2048 / 1024 token；
proposer 上限仍为 6144。它是新的适配版本实验，不是首次运行的延续或严格单变量消融。
仍有五次 JSON 解析拒绝和六次 critic 拒绝；结构化生成遇到输出长度上限仍可能被截断。

第二次运行的三个父版本切换均由决策器自动完成；候选源码与模型原始提案逐一匹配。
留出准确率增加 3.91 个百分点，平均 policy token 减少 21.01%。
按问题聚类的配对 bootstrap（10000 次，seed=7308）给出的准确率差值 95% 区间为
[0.39, 7.81] 个百分点。这只是单次小规模 pilot，尚未验证完整 MATH-500、多随机种子或原论文领域。

最终候选改写了解题提示并增加截断恢复分支。最终留出评测的 256 个 trial 均只有一次模型调用，
恢复分支没有执行，因此这次结果不能证明该结构机制的收益。
21.01% 是解题时的单题 token 节省，不包含搜索成本；第二次运行的分析、提案和 critic
合计消耗 95963 token，另有搜索阶段的候选解题成本。

正式接口、Lab、服务与传输适配由框架维护；提案、修复、评测请求、采纳与父版本切换由决策器执行。
维护者没有手工修补候选或指定赢家。原始轨迹、模型调用、源码快照及两份证据归档均保留在本次
运行的 `.local/rrsi-harness-20261108/` 下，不将临时运行产物纳入公开源码。
